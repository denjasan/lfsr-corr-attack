# lfsr-corr-attack
Реализация корреляционной атаки на заданный комбинирующий генератор над GF(2): C++ с OpenMP

## Структура проекта
```
lsfr-corr-attack/
├── src/
│   ├── main.cpp
│   ├── lib.cpp     # общие функции для проекта      
│   ├── seq.cpp     # CPU последовательно
│   ├── par.cpp     # OpenMP параллельно
│   └── gen.cpp     # генерация входных данных
├── include/        # внутренний api
├── Makefile
├── README.ru.md
└── README.md
```

## Сборка и запуск проекта
```
make
./lsfr_corr_attack seq
```

## Постановка задачи

Известно описание комбинирующего генератора:

- количество используемых регистров сдвига n;
- их длинны Li, i = 1, ..., n;
- их полиномы обратной связи ci(v);
- комбинирующая булева функция f.

Необходимо найти начальное заполнение каждого LSFR.
