# lfsr-corr-attack
Реализация корреляционной атаки на заданный комбинирующий генератор над GF(2): C++ с OpenMP

## Структура проекта
```
gf2-corr-attack/
├── src/
│   ├── lib/        # библиотеки для проекта      
│   ├── seq/        # CPU последовательно
│   ├── par/        # OpenMP параллельно
│   └── gen/        # генерация входных данных
├── Makefile
├── README.ru.md
└── README.md
```

## Сборка проекта
```
make
./seq
./par
```
